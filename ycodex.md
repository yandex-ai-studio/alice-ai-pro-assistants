# YCodex: установка и запуск

YCodex — консольный ИИ-ассистент для разработки. Он работает в терминале: читает код
в вашем проекте, предлагает и вносит правки, запускает команды и отвечает на вопросы
по репозиторию. Доступ предоставляется по подписке **Алиса AI Про**.

Оформить подписку: <https://aistudio.yandex.ru/manage>

## Требования

- macOS или Linux (x86_64 либо arm64).
- Аккаунт Yandex Cloud с активной подпиской «Алиса AI Про».
- Идентификаторы облака и каталога, в которых оформлена подписка.

## Установка

```bash
curl -sSfL https://storage.yandexcloud.net/yc-codex/install.sh | bash
```

Скрипт скачает последнюю версию и установит её в `~/yc-codex/bin`. Чтобы команда
`ycodex` стала доступна в терминале, перезапустите оболочку:

```bash
exec -l $SHELL
```

Если инсталлятор не смог обновить файл профиля автоматически, он подскажет строку,
которую нужно добавить в `~/.bashrc`, `~/.zshrc` или аналогичный файл.

Проверьте установку:

```bash
ycodex --version
```

## Вход в аккаунт

```bash
ycodex --cloud <cloud-id> --folder <folder-id> login
```

Откроется браузер — подтвердите доступ к Yandex Cloud. После этого YCodex готов к работе.

## Запуск

```bash
ycodex --cloud <cloud-id> --folder <folder-id>
```

- `<cloud-id>` — идентификатор облака Yandex Cloud;
- `<folder-id>` — идентификатор каталога, в котором оформлена подписка.

Чтобы не указывать параметры при каждом запуске, запишите их один раз в файл
`~/.yc-codex/config.toml`:

```toml
cloud  = "<cloud-id>"
folder = "<folder-id>"
```

После этого достаточно команды `ycodex`.

## Выбор модели

По умолчанию используется модель DeepSeek. Список доступных моделей и переключение между
ними — командой `/model` прямо в интерфейсе.

## Обновление и диагностика

```bash
ycodex update   # обновить до последней версии
ycodex doctor   # проверить установку, вход и доступ к сервису
```

## Удаление

```bash
rm -rf ~/yc-codex
```

Затем удалите из файла профиля (`~/.bashrc`, `~/.zshrc` или аналог) строку,
добавляющую `~/yc-codex/bin` в `PATH`.
